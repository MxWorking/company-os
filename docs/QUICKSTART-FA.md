# راه‌اندازی سریع Company OS 2.0 (نسخه بررسی)

**این نسخه برای آزمایش و توسعه است، نه ورود اطلاعات محرمانه واقعی.** در حالت Demo داده‌ها نمونه‌اند و برای استفاده عمومی مناسب نیستند.

## گزینه اول: Docker Desktop در ویندوز

در پوشه اصلی پروژه (همان پوشه‌ای که `docker-compose.yml` دارد) اجرا کن:

```powershell
docker compose up --build
```

سپس مرورگر: `http://localhost:3000` و مستندات API: `http://localhost:8000/docs`.

## گزینه دوم: اجرا بدون Docker

ترمینال PowerShell شماره ۱، از پوشه `backend`:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt -r requirements-dev.txt
$env:APP_ENV="development"
$env:DEMO_MODE="true"
python -m uvicorn main:app --reload --port 8000
```

ترمینال PowerShell شماره ۲، از پوشه `frontend`:

```powershell
npm install
npm run dev
```

در `frontend/.env.local` بنویس: `BACKEND_URL=http://127.0.0.1:8000`

## مسیرهای بررسی

۱. ابتدا روی Hero ویترین دکمه «ورود به سامانه» را بزن یا اسکرول کن.
۲. از سایدبار «سازمان و اعضا» را باز کن؛ واحد/تیم/سمت و مدیریت اعضای سازمان در همین بخش است.
۳. برای پروژه/بورد/تسک از «پروژه‌ها و بوردهای پیشرفته» استفاده کن.
۴. در «کارهای من» وظایف متعلق به حساب خودت را ببین؛ برای تسک در فرم، عضو سازمان را انتخاب کن.
۵. «منابع انسانی» قدیمی شامل پرونده پرسنلی است؛ «منابع انسانی پیشرفته» قرارداد، مرخصی و دارایی پرسنلی را ثبت می‌کند.
۶. از منوهای «گفتگو و جلسات»، «مکاتبات»، «مشتریان و فروش»، «مالی و زمان‌کاری» و «گزارش‌ها و اتوماسیون» باقی بخش‌ها را تست کن.
۷. در Settings تغییر Light/Dark و در Header زبان FA/EN را آزمایش کن.

## آزمون‌ها

```powershell
# Backend terminal
python -m pytest -q
# Frontend terminal
npm run typecheck
npm run build
```

تست‌های Python در محیط آماده‌سازی پاس شده‌اند. Build و Typecheck واقعی Next.js در این محیط به دلیل عدم دسترسی npm تأیید نشده‌اند و باید روی دستگاه تو اجرا شوند.
